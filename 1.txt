роект 1: Telegram-бот "WB Price & Stock Tracker"
Закрывает требования: "Интеграции с маркетплейсами", "Telegram-боты", "Парсеры".
Функции: Пользователь отправляет артикул товара Wildberries. Бот получает текущую цену, скидку и остаток на складах, сохраняет историю в локальную БД. Раз в сутки бот проверяет изменения и отправляет push-уведомление, если цена упала или товар заканчивается.
Ресурсы (API): Публичные endpoints Wildberries (не требуют ключа продавца). Например, эндпоинты для карточек товаров (card.wb.ru) и поиска (search.wb.ru).
Библиотеки: aiogram (v3.x), httpx (асинхронные HTTP-запросы), aiosqlite (асинхронная SQLite), asyncio.
Промпт для Cursor:
"Создай структуру Telegram-бота на Python (aiogram v3) и FastAPI/HTTPX. Бот принимает артикул Wildberries, делает асинхронный GET-запрос к публичному API карточек WB (найди актуальный URL для получения цены и остатков по артикулу), парсит JSON-ответ и сохраняет артикул, цену и дату в базу данных SQLite через aiosqlite. Настрой Celery или apscheduler для ежедневной проверки сохраненных артикулов и отправки алертов в Telegram, если цена изменилась."
Проект 2: AI-Аналитик отзывов (Sentiment Analysis)
Закрывает требования: "AI-решения", "Системы отчетности".
Функции: Бот принимает ссылку на товар, парсит последние 50 отзывов, отправляет их в LLM (YandexGPT или OpenAI) с промптом "Выяви топ-3 проблемы товара и топ-3 преимущества, верни результат в виде JSON".
Ресурсы: Публичный API отзывов WB (feedbacks1.wildberries.ru), API YandexGPT (или OpenAI).
Библиотеки: aiogram, httpx, yandex-cloud-ml-sdk (или openai), pydantic (для строгой валидации JSON, который возвращает нейросеть).
Промпт для Cursor:
"Напиши скрипт на Python, который асинхронно парсит отзывы с Wildberries по артикулу (используя их публичный endpoint для отзывов). Затем скрипт должен формировать промпт, передавать текст отзывов в YandexGPT API (или OpenAI) для анализа тональности и извлечения сущностей. Ответ от LLM должен строго валидироваться через Pydantic модель, чтобы гарантировать, что мы получаем структурированный JSON с полями 'pros' и 'cons'."
Проект 3: Генератор PDF-отчетов для менеджеров
Закрывает требования: "Автоматизация бизнес-процессов", "Аналитика".
Функции: Скрипт читает CSV-файл с продажами (симуляция выгрузки из CRM), вычисляет маржинальность, строит график топ-10 товаров и генерирует PDF-отчет, который бот отправляет "директору" в Telegram.
Ресурсы: Mock-данные (CSV), генерируемые скриптом.
Библиотеки: pandas (анализ данных), matplotlib (графики), reportlab или fpdf2 (генерация PDF), aiogram.
Промпт для Cursor:
"Напиши backend-сервис на Python. Он должен читать CSV файл с mock-данными продаж через pandas, рассчитывать общую выручку и маржу, строить график с помощью matplotlib и сохранять его как изображение. Затем с помощью библиотеки reportlab создай PDF-отчет, вставив туда текст и картинку графика. В конце добавь функцию отправки этого PDF файла в Telegram через aiogram."
Проект 4: Платежный шлюз для AI-подписки
Закрывает требования: "Telegram-ботов с платежами".
Функции: Бот предоставляет доступ к Проекту 2 (AI-аналитике) только после оплаты подписки через Telegram Stars или тестовый режим ЮKassa.
Ресурсы: Telegram Bot Payments API.
Библиотеки: aiogram (работа с PreCheckoutQuery и SuccessfulPayment).
Промпт для Cursor:
"Реализуй в aiogram v3 обработку платежей через Telegram Payments. Создай команду /subscribe, которая отправляет инвойс пользователю. Напиши обработчики для pre_checkout_query и successful_payment, которые после успешной оплаты обновляют статус пользователя в SQLite базе данных, давая ему доступ к AI-функциям бота."
